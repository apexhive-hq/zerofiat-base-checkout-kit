Core Engineering Modules

EOA + Smart Wallet Verifier

Aggregates BigInt 6-decimal Base USDC Transfer logs across multi-RPC failover (BASE_RPC_URLS) and verifies variable-length ERC-1271 / EIP-6492 + EIP-191 signatures via viem.

Atomic Durable Object Lock

TxClaimLockDO serializes concurrent requests per scoped claim key inside a single-threaded SQLite-backed Durable Object, preventing concurrent replay races.

Ed25519 Receipt Certificates

Issue portable WebCrypto Ed25519 attestation tokens via /api/challenge + /api/verify for offline verification, or run server-to-server checks via POST /api/hosted/verify.
